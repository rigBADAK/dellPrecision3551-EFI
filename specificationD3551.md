## Technical Notes (i7-10850H Specific)
- i7-10850H is the vPro version of i7-10750H (same 6C/12T, differs in vPro + slightly higher turbo)
- Thermal throttling common under sustained load - undervolting via ThrottleStop/Intel XTU recommended
- Supports Intel TXT, VT-d, VT-x for virtualization
- Memory Controller: Dual-channel DDR4-2933 (official), supports 3200MHz XMP
- PCIe Lanes: 16 (CPU) + 24 (PCH) = 40 total
- No integrated Thunderbolt controller - uses Titan Ridge (JHL7540) retimer
